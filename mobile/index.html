把厚厚一份 PDF
變成剛好的章節。

依書籤或頁數拆分，也能不拆分、直接產生文件摘要。

尚未選擇檔案

選擇檔案即可開始。

處理設定

每次最多 50 頁，依頁序擷取最多 24,000 字，產生最多 300 字摘要。只摘要所選範圍，不代表整份文件；超過文字上限會截取。不建立 PDF 或 ZIP，完成後原始暫存檔立即刪除。

智慧摘要（選用）

摘要模型：Gemini 3.8 Flash（gemini-3.8-flash）。勾選後，拆分模式會將各章首頁最多 8,000 字傳送至 Google；只摘要模式會傳送所選範圍最多 24,000 字，可能產生 API 費用。不執行 OCR，金鑰不存入瀏覽器儲存空間。

文件摘要結果

原始 PDF 暫存已清除，沒有建立章節 PDF 或 ZIP。結果保留至工作到期，請先複製保存。若摘要失敗，處理錯誤後重新上傳即可再試。

章節已整理完成

下載章節 ZIP

下載串流送出後會刪除伺服器檔案。請保留下載的 ZIP。

部分摘要未完成，PDF 與 ZIP 仍可下載。首次 API 錯誤後已暫停後續摘要。請依下方錯誤提示處理，下載 ZIP 後重新上傳 PDF，再啟用摘要重試；不需要提供 API Key 給維護者。

安裝到手機

Android：Chrome 選單 →「安裝應用程式」或「加到主畫面」。iPhone：Safari 分享 →「加入主畫面」。

需使用 HTTPS 網址。安裝後仍需網路與伺服器才能拆分；離線只能開啟介面。大型上傳期間請保持畫面開啟，手機切到背景可能中斷。

上傳新文件會清除上一份檔案。工作預設保留 30 分鐘，未下載的檔案也會自動清理。
